# SEOUL / LAST SIGNAL — 한국의 두 장소 사이를 살아서 건너는 좀비 생존

`Play.cmd`를 두 번 클릭하면 Windows 실행본이 열립니다. 실행본이 없으면 Unity 에디터가 열립니다. 에디터에서 `Assets/Game/Scenes/SeoulSurvival.unity`를 열고 ▶를 누르세요. 씬에는 GameBootstrap 하나만 필요하며, 모든 게임 오브젝트와 UI가 자동 생성됩니다.

**다른 Windows 컴퓨터에서 바로 테스트:** `Builds/Portable/SeoulLastSignal-Windows.zip` 하나를 옮겨 압축을 풀고 `Verify.cmd` → `Play.cmd` 순서로 실행하세요. Unity 설치가 필요 없습니다. 자세한 절차는 `Docs/PORTABLE_TEST.md`에 있습니다. 현재 개발은 PC를 우선하며 `Builds/Android/SeoulLastSignal.apk`는 이전 PC 기능 업데이트 전의 APK입니다.

첫 화면에서 **“당신은 어디에 있나요?”**, **“당신의 소중한 사람은 어디에 있나요?”**에 답하세요. 현재는 `노원역`, `잠실역`, `강남역`, 세 지역의 번들 지도에 수록된 정확한 시설명(예: `노원문고`, `노원 롯데백화점 노원점`) 또는 한국 내 `위도,경도` 숫자를 지원합니다. 기본 여정은 노원역→잠실역입니다. 중복된 시설명은 임의로 한 곳을 고르지 않습니다. GPS 자동 위치와 전국 임의 주소 검색은 아직 없습니다.

## 전체 코드와 파일 위치

- `Assets/Game/Scripts/`: 게임 C# 코드 전체 원문. 코드 복사 작업 없이 프로젝트에 들어 있습니다.

- `Assets/Game/Scenes/SeoulSurvival.unity`: 자동 준비된 시작 씬.
- `Docs/FULL_SOURCE.md`: 모든 자체 C# 코드 전문을 생략 없이 모은 문서.
- `Docs/ASSET_AND_RELEASE_GUIDE.md`: 모델·Mixamo·건물·소리 교체 및 PC/모바일 전환 순서.
- `Docs/ARCHITECTURE.md`: 컴포넌트 연결, 좌표 및 청크 설계, 제한 사항.
- `Docs/VERIFICATION.md`: 실제로 수행한 검사와 미검증 항목.
- `Docs/ART_LICENSES.md`: 실제 적용한 Kenney CC0 에셋과 글꼴 라이선스.
- `Docs/DEPENDENCIES.md`: 도입 도구, 고정 버전과 라이선스 출처.
- `Tools/`: 프로젝트 전용 MCP 서버, 자동화 및 재설치 스크립트.
- `Builds/Windows/`: Windows 빌드 전체. exe 파일 하나만 옮기지 마세요.
- `Builds/Portable/SeoulLastSignal-Windows.zip`: 다른 컴퓨터로 옮길 테스트 묶음과 파일 무결성 검사.

기존 상위 폴더의 웹 게임/파이프라인은 원래 경로를 유지합니다. Unity에 필요한 파일들은 이 폴더로 모았으며, 기존 게임을 무작정 이동해 실행을 깨뜨리지 않았습니다.

## 지금 할 수 있는 플레이

1. WASD로 이동하고 마우스로 방향을 정합니다. 우클릭을 0.6초 유지해 조준선을 초록색으로 모은 뒤 좌클릭하면, 장애물 없이 맞힌 좀비에게 헤드샷 4배 피해가 들어갑니다.
2. 1은 가상의 구호 권총, 2는 소방도끼, 3은 파밍 재료로 제작하는 가상의 현장 조립 소총입니다. R로 재장전합니다. 권총·소총 탄창은 따로 저장되고 예비 탄약은 공유합니다. 도끼는 탄약 대신 기력을 써서 전방 부채꼴을 공격합니다. 실존 브랜드·총기 모델명은 쓰지 않습니다.
3. 파란 경찰서, 빨간 소방서, 노란 편의점, 초록 학교, 회색 업무지구, 갈색 주택에 들어가세요. 남쪽 입구를 통과하면 지붕이 열립니다. 상자 가까이에서 E로 즉시 수색하면 물자를 빨리 얻지만 큰 소음과 이후 추격 압력이 올라갑니다. V로 2.5초 동안 정밀 분해하면 피격 시 중단되는 위험을 감수하는 대신 소음과 추격 증가가 작고 추가 부품을 얻습니다. 폴백 지도에는 환승 거점·주택 골목·상업 거리의 세 배치가 나타나며, V 정밀 분해 보상은 각각 배터리·생수·식량입니다.
   주민센터 거점에서 B를 눌러 시설 회수 의뢰를 받으면, M 지역도에서 노란색으로 표시된 미개봉 대상 시설을 수색한 뒤 거점으로 돌아와 추가 보상을 받을 수 있습니다. 완료할 때마다 다음 시설 의뢰가 열리고 진행 상황은 저장됩니다.
4. 학교와 업무지구에서 고철/전자부품을 모은 뒤 C를 누르고 수리 키트를 만드세요. 같은 창에서 탄약·바리케이드·유인 신호탄(Q)을 만듭니다. 신호탄은 조준 방향 앞에 떨어져 잠시 좀비를 그 위치로 끌어들입니다. 편의점·주택에서는 생수를 얻고 T로 마셔 기력을 회복합니다. 업무지구의 배터리는 전기 스쿠터 충전에 쓰며 전자부품도 대체할 수 있습니다. 조합 창을 열어도 시간이 흐릅니다.
5. H로 구급상자/식량을 사용합니다. 북쪽 보라색 송신탑 가까이에서 E를 눌러 수리 키트를 투입하세요.
6. 탑 반경 40m 안에서 신호를 유지하며 60초 생존하면 헬기와 승리 화면이 나타납니다. **20초마다 총을 들고 탑을 향해 우클릭을 유지**하세요. 조준 수축 후 1.2초간 동기화하면 신호가 갱신됩니다. 신호가 끊기거나 구역 밖으로 나가면 구조 타이머가 멈추고 좀비는 계속 몰려옵니다. 작전 성공 후 주민센터로 복귀하면 물자와 성장 상태를 유지한 채 다음 지역 작전으로 이어집니다. 헬기 구조는 게임의 끝이 아닙니다.

7. 출발지 근처 자전거와 배달 전동 스쿠터에는 G로 탑승/하차합니다. 자전거는 조용하지만 기력을 소모하고, 스쿠터는 빠르지만 배터리 거리와 소음 때문에 추격을 부릅니다. 스쿠터 곁에서 J를 누르면 배터리 1개 또는 전자부품 1개로 충전합니다. 주민센터(시작점 남쪽)에서 B로 거점/작업대를 개선하고 식량을 소비해 휴식하면 추격 압력도 내려갑니다. F는 식사, T는 생수 우선·없으면 기력 음료, F5는 저장입니다. 거점에서는 새 여정을 고를 수 있습니다.
8. 45초마다 자동 저장하며 다음 실행에서 이어집니다. 송신탑 방어 중에는 시작 직전 체크포인트를 유지하고, 목적지 방어의 남은 시간은 저장합니다. 자세한 저장 범위와 복구는 `Docs/SAVE_SYSTEM.md`에 있습니다.

여정 전투에는 일반·질주·중장 감염자가 섞입니다. 초반에는 일반형만 나타나고, 진행도 25%부터 빠른 질주형, 65%부터 몸통 사격에 강한 중장형이 등장합니다. 중장형은 정밀 헤드샷으로 몸통 방어를 무시할 수 있습니다. 등장 비율과 능력은 `Assets/Game/Resources/GameBalance.asset`의 Journey / Zombie Variants에서 바꿉니다. 캐릭터 모델은 GameBootstrap의 Assets 슬롯에서 Runner Zombie Prefab, Armored Zombie Prefab으로 각각 교체할 수 있습니다. 슬롯을 비워두면 색과 표시가 있는 기본 도형으로 작동합니다.

노원→잠실 여정에는 주택가 임시 진료소, 한강 접근 봉쇄선, 목적지 인근 무전 중계의 세 선택 사건이 있습니다. 식량을 약품으로 교환할지, 기력을 써서 우회할지, 전자부품으로 조용히 연락할지 결정합니다. 경보·공개 송신은 즉시 좀비를 부르고 이후 추격 압력도 높입니다. 선택과 추격 수치는 저장되어 같은 보상을 다시 받을 수 없습니다. 목적지에 도착하면 약속 장소 근처에서 기본 45초 방어해야 재회합니다. 방어 범위를 벗어나면 타이머가 멈춥니다.

지도 건물은 OSM에 윤곽과 높이 태그가 있으면 실제 크기·층수에 맞춰 표시하고, 없는 층수는 추정이라고 적습니다. 가까운 건물의 이름·층수와 OSM/절차 지도 여부는 M 지역도에 나타납니다. 먼 목적지는 지도 가장자리의 노란 표시로 방향을 보여주며, 확대 지도에 남은 **직선거리**가 적힙니다. 총성·소음 수색·스쿠터·사이렌은 해당 동네와 이웃 동네의 **감염 압력**을 올립니다. 붉게 칠해진 청크에서는 여정 조우가 늘어나고, 시간이 지나면 압력이 내려갑니다. 지역도에 현재 압력이 표시되므로 조용히 이동하거나 다른 블록으로 우회할 수 있습니다. OSM 공원 경계는 지도와 게임 지상에 녹색으로 표시됩니다. 일부 OSM 건물은 지상 1층 출입구·가상 실내·상자가 생기며, 들어가거나 카메라 시야를 가리면 지붕/상부 벽이 열립니다. 위층의 실제 도면이나 모든 건물의 실내는 아직 구현되지 않았습니다.

게임의 차별화 방향과 새 규칙은 `Docs/GAME_IDENTITY.md`에 정리했습니다.

인터넷 없이 시작해도 노원·잠실·강남역 중심 청크는 OSM 도로·건물 외곽선 표본을 표시하고 주변 청크는 즉시 폴백 도시로 이어집니다. 인터넷이 연결되면 다른 청크를 OSM으로 보강합니다. `M`으로 확대 지역도를 열 수 있습니다. 실제 OSM 도로/시설 좌표와 게임용 폴백 시설을 함께 표시합니다. 실내, 건물 높이, 출입문은 실제 현장 도면이 아닌 가상 구조입니다. 목표까지의 방향·직선 거리와 진행도에 따라 위협이 증가합니다. **현실 도로의 길찾기·교량 통과 가능성은 아직 계산하지 않으므로 실제 길 안내로 사용하면 안 됩니다.** GPS 권한이나 사용자의 현재 위치를 자동 수집하지 않습니다.

## 숫자 수정

가장 쉬운 방법은 수치 변경을 Codex에게 요청하는 것입니다. 직접 바꾸려면 Unity Project 창에서 `Assets/Game/Resources/GameBalance.asset`을 선택해 Inspector 값을 수정하세요. Play 중 바꾼 값은 종료하면 사라지므로 정지 상태에서 편집하세요.

## 자동화

Unity 상단 `Seoul Survival` 메뉴에서 씬 준비, Windows 빌드, Android APK/AAB 빌드, 로컬 MCP 연결을 실행할 수 있습니다. APK는 `Tools/Unity.ps1 -Mode BuildAndroidApk`로도 생성됩니다. Android Build Support와 SDK/NDK·OpenJDK 모듈 설치가 필요합니다.

에디터가 닫혀 있을 때 `powershell -File Tools/Unity.ps1 -Mode Check`로 회귀 검사를 재실행합니다. 검사 전용 실행은 끝나면 에디터가 종료됩니다. `-Mode BuildWindows`로 Windows 빌드를 재생성합니다. 기존 씬의 에셋 슬롯은 보존됩니다.

Unity MCP는 `Start-MCP.cmd`로 로컬 127.0.0.1:8080에서 시작합니다. 이 작업에서는 MCP 클라이언트로 실제 플레이/콘솔/스크린샷을 제어했습니다. 새 Codex 대화의 도구 목록에 자동 등록되는 것과는 별개이며, 로컬 클라이언트 `Tools/mcp_client.py`도 사용할 수 있습니다.

FreeLLMAPI는 프로젝트 옆 `freellmapi/`에 별도로 두고, 개발용 초안만 `Tools/AI-Drafts/`에 저장합니다. 계정·모델 연결 및 한 번만 필요한 통합 키 입력 방법은 `Docs/FREELLM_WORKFLOW.md`에 있습니다. 게임 빌드에는 API 키나 AI 서버를 포함하지 않습니다.

## 개발 단계

현재 단계는 장기 생존 기반을 갖춘 개발 빌드입니다. Kenney 모델·대기/달리기 모션·생존 소품과 한글 글꼴을 적용했습니다. 전용 공격 모션·녹음 효과음/BGM은 후속 작업입니다. 다음 단계는 한 구역의 그래픽/사운드 완성 → 장기 콘텐츠 및 전투 밸런스 → Android 실기기 최적화 → 스토어 출시 검증입니다. 상세 조건은 가이드를 참고하세요.
