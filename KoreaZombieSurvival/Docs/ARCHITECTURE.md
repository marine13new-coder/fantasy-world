## 지도와 메모리

반경 400m를 중심에서 가장자리까지로 정의하고, 한 청크의 변 길이는 800m입니다. 플레이어를 포함한 3×3 청크(최대 9개)를 유지하며, 중심 경계를 넘으면 다음 열/행을 생성하고 먼 청크 오브젝트를 파괴합니다. Overpass는 각 청크의 800×800m 사각형을 요청하고, 응답 요소 2000개·본문 4MB·표시 건물 90개/청크로 제한합니다. 북/동/남/서 경계를 넘으면 새 청크를 생성하고 두 칸 이상 멀어진 청크와 그 건물·도로를 해제합니다.

선택한 출발지를 원점으로 위도 1도=111320m, 경도는 원점 위도의 cos 보정을 씁니다. 도심 근거리 프로토타입용 지역 평면 근사입니다. 입력은 정확한 노원역·잠실역·강남역 이름이나 한국 범위의 위도/경도 쌍만 지원하고, 출발~목적지 직선 거리 0.5~80km만 받습니다. 목적지 안내는 직선 방향·거리이므로 실제 도로/교량 경로가 아닙니다. 대한민국 전역을 장거리 연속 이동하는 상용판에는 측지 투영/부동 원점과 실제 도로 경로 탐색이 필요합니다. 휴대폰 GPS 기반 이동 기능은 이번 시범판에 포함되지 않습니다.

노원·잠실·강남 주변은 번들 OSM 표본을 우선 읽습니다. 다른 청크의 API 요청은 직렬, 타임아웃 15초, 요청 후 3초 간격이며 응답 길이/좌표/요소 수를 검증합니다. 캐시는 persistentDataPath/osm에 7일, 최대 128개 파일입니다. OSM 건물은 실제 윤곽과 기록된 높이/층수 태그를 사용하며 태그가 없으면 추정치로 표시합니다. POI가 건물 윤곽 안에 있으면 그 건물의 수색 가능한 가상 1층에 연결합니다. 청크당 가장 가까운 일반 건물 최대 6개에도 가상 1층을 만듭니다. 지붕과 상부 벽은 플레이어가 들어가거나 카메라 시야를 막으면 가리고, 충돌 벽은 유지합니다. 기본 필수 시설 6개는 폴백에 유지해 시골/시설 부족에서도 탈출 재료를 확보할 수 있습니다. 폴백 청크는 좌표 기반으로 환승 거점·주택 골목·상업 거리 3종을 결정하고 시설을 각각 다른 간격으로 배치합니다. 폴백 도로도 지역도에 표시하며 실제 OSM 도로를 받으면 해당 청크의 폴백 도로를 지웁니다. 추가 OSM 시설은 청크당 20개, 도로 선분 350개로 제한합니다. 시설/도로의 게임 충돌 배치는 실제 지형 재구성이 아닌 프로토타입 수준입니다.

지역 유형은 청크 좌표에서 결정되며 같은 장소를 다시 로드해도 바뀌지 않습니다. V 정밀 분해의 추가 보상은 `GameBalance.asset`의 `carefulDistrictBonus` 순서(환승/주택/상업)로 조절합니다. OSM에 실제 용도지역 데이터가 없을 때 적용하는 **게임 규칙**이며, 실제 지역의 상업·주거 구분을 주장하지 않습니다.

NavMesh는 전체 한국 대신 플레이어 주변 180×180m에서 정적 충돌체(레이어 8)로 만듭니다. 35m 이동 또는 지도 변경 시 다시 계산합니다. 멀리 있는 좀비는 NavMesh가 준비될 때 활성화됩니다. 동시에 살아 있는 좀비는 70마리로 제한합니다. 모바일 확장 시 NavMesh 비동기 갱신과 풀링, 프레임 예산 분할이 우선입니다.

## 상태와 이벤트

플레이어: Idle / Move / FocusAim / Shoot / MeleeSwing / Reload / Interact / Dead. 죽음은 다른 행동보다 우선하며 장전/역경직 코루틴을 취소합니다. 좀비: Idle / Patrol / Chase / Attack / HeadshotStun / Dead. 총성은 HearNoise에 위치와 반경을 전달하며, 시야는 거리/전방 각도/벽 가림을 확인합니다.

빠른 상자 수색은 `GameBalance.pursuit`의 큰 소음과 여정 추격 압력 증가를 적용합니다. 정밀 수색은 작은 소음을 내고 피격/이동 시 중단되며 추가 자원을 줍니다. 총격도 추격 압력을 조금 올리고, 시간 경과 또는 거점 휴식으로 가라앉습니다. 기존 `JourneyDirector.Alert`가 조우 숫자·체력에 영향을 주며 `CampaignData.journeyAlert`로 저장되므로 새 저장 형식은 필요하지 않습니다.

정밀 사격 100%는 '조준선을 모은 뒤 실제 Raycast가 맞은 대상의 헤드샷 판정 100%'입니다. 벽 또는 허공을 향해 쏴도 적에게 명중하는 자동 조준은 아닙니다. 도끼는 각도+거리+가림 검사입니다. 역경직은 실제 시간 0.06초 동안 timescale 0.05, 이후 복구합니다.

획득 상자/죽은 좀비의 ID, 인벤토리, 탄약, 체력, 생존 시간, 거점/작업대 레벨과 작전 횟수를 JSON에 저장합니다. 다음 실행에서도 파밍 중복을 방지합니다. 방어 도중 저장은 직전 체크포인트를 유지하며 설치한 바리케이드는 아직 저장하지 않습니다. Docs/SAVE_SYSTEM.md를 참고하세요. 국가 규모 세션의 이력 저장은 상용화 단계에서 청크별 영속 저장소로 옮겨야 합니다.

최종 방어의 신호 유지 시간(signalWindowSeconds=20)과 조준 동기화 시간(signalLockSeconds=1.2)은 JSON/Inspector에서 조절합니다. 탑 정밀 조준은 전방 각도, 벽 가림, 사격 상태를 검사합니다. 신호 유효 시간 동안만 구조 타이머가 진행되며, 신호가 꺼져도 웨이브는 멈추지 않습니다.

## 한계와 다음 개발

- 실제 건물 외관 사진/실내 도면/층별 구조는 취득하지 않습니다. 시설 좌표만 실제 데이터입니다.
- 캐릭터는 Kenney 모델과 대기/달리기 모션, 소품은 Survival Kit를 적용했습니다. 건물은 절차적 구조에 한글 간판/창문/가구를 더했습니다. 공격 모션과 음향은 절차적 대체 표현이며 교체 슬롯이 연결됩니다. 동작 중 Inspector 슬롯만 바꿔 이미 생성된 모든 오브젝트를 실시간 재생성하는 편집기는 없습니다. 슬롯 변경 후 Play를 다시 시작합니다.
- Steam 업적/클라우드/결제, Android 저장/백그라운드 복귀, 패드/접근성 옵션은 미구현입니다.
- 공용 Overpass 장애 시 폴백은 계속 작동합니다. 상용 트래픽에는 배포 전 캐시된 지도 팩 또는 운영 가능한 지도 백엔드를 준비합니다.
