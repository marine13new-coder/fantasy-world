# 장기 생존 저장과 복구

45초마다, 거점 개선/휴식/복귀 시, 종료 또는 앱 백그라운드 전환 때 저장합니다. F5는 수동 저장입니다. 사망 상태는 이전 생존 체크포인트를 덮어쓰지 않습니다.

Windows 기본 위치는 `%USERPROFILE%/AppData/LocalLow/Seoul Survival Studio/Seoul Last Signal/`입니다. 선택한 여정은 `journey-v1.json`, 해당 출발·도착 좌표의 생존 기록은 `campaign-v1-<좌표>.json`으로 분리합니다. 예전 강남 시범판은 `campaign-v1.json`을 사용합니다. Android는 앱 전용 persistentDataPath를 씁니다. 주민센터에서 B를 열어 새 여정을 선택하면 이전 여정의 생존 기록은 보존됩니다.

보존 대상: 출발·도착 장소와 재회 여부, 세 여정 사건의 선택 이력·추격 압력·최종 방어 남은 시간, 동네별 감염 압력(최대 64청크), 경과 시간, 체력/포만감/기력, 위치, 권총·소총의 별도 탄창과 예비 탄약, 보유·장착 무기, 자전거·스쿠터 위치와 남은 주행 거리, 인벤토리, 획득 상자/죽은 고정 좀비 ID, 거점/작업대 레벨, 구호 작전 완료 수, 시설 회수 의뢰 수락·회수·완료 수, 성공 후 복귀 대기 상태. 이전 저장 파일의 단일 탄창 형식과 감염 압력 필드가 없는 저장 파일도 읽습니다.

임시 파일을 쓴 뒤 원본을 교체하고 `.bak` 백업을 남깁니다. 원본 손상 시 백업을 검사합니다. 둘 다 손상되면 자동 덮어쓰기를 차단하고 원본을 보존합니다. 복구가 필요하면 파일을 별도 복사해 Codex에게 분석을 요청하세요. 새 게임은 게임 종료 후 json과 bak을 다른 이름으로 보관하면 시작됩니다.

송신탑 방어 웨이브 중에는 저장을 유예하고 작전 직전 체크포인트를 유지합니다. 목적지 재회 방어의 남은 시간은 저장할 수 있습니다. 개별 웨이브 적과 설치한 바리케이드의 영속 저장은 미구현입니다. 종료하면 임시 바리케이드는 사라지며 사용한 제작 재료는 돌아오지 않습니다.

주민센터 반경 9m는 준비와 휴식을 위한 안전 구역입니다. 이 안에서는 좀비가 공격을 멈춥니다. 거점 공격 이벤트는 후속 개발 대상입니다.

자동 검사는 `Logs/campaign-check-<GUID>.json`을 사용해 실제 사용자 저장 파일을 보호합니다. 현재 저장 형식 version 1이며 알 수 없는 버전은 거부합니다.
